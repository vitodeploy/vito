# Contributing

Vito does not accept pull requests. You can contribute by
[reporting bugs](https://github.com/vitodeploy/vito/issues/new?template=bug_report.yaml) and
[sharing ideas](https://github.com/vitodeploy/vito/discussions/new?category=ideas) with as much detail as possible.

Please read the full contribution guide on the website:

https://vitodeploy.com/docs/prologue/contribution-guide
