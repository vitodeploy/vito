# VitoDeploy Documentation — 2.x

> **Reading this as an LLM?** Append `/plain` to any docs URL for that page's raw Markdown.

VitoDeploy is a free, open-source, self-hosted server management tool. Provision servers, manage
databases, deploy sites, and more — all from a clean dashboard.
